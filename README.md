# Tactile Theme

Custom Shopify Theme developed by **Pixelotech** for **Ellora Surfaces**.

## Architecture
- **Theme Name**: Tactile
- **Theme Version**: 1.0.0
- **Author**: Pixelotech (https://pixelotech.com)
- **Framework**: Shopify Online Store 2.0 (OS 2.0)

## Folder Structure
- `assets/` - Stylesheets, JavaScript modules, fonts, SVGs
- `config/` - `settings_schema.json` and theme configuration
- `layout/` - Master layout templates (`theme.liquid`, etc.)
- `locales/` - Language translation files
- `sections/` - Custom and dynamic theme sections
- `snippets/` - Reusable liquid components
- `templates/` - JSON and liquid page templates
